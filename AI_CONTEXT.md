Current state of the repository for an agent starting work today. Keep it short: history goes to

## Project summary

Quick Delivery is a multi-tenant SaaS marketplace: customers book delivery, ride (backend category
`transport`) and shipping services offered by tenant owners, whose employees (couriers/drivers) carry out
the jobs. It has real-time chat, live location tracking, escrow/wallet accounting, subscriptions, KYC and
support tickets. The backend is Go microservices on Docker Compose with MongoDB and Redis. The client is
one Flutter app. The repo is called `saas-core` internally.

## Architecture

All client traffic goes through api-gateway, which reverse-proxies to the services. Ports are the
defaults from `infrastructure/.env.example`.

| Service | Port | Role | Data store |
| :--- | :--- | :--- | :--- |
| api-gateway | 8080 | Edge proxy, path rewrite, rate limiting, client version gate (ADR-0018) | Redis |
| auth-service | 3002 | Signup/login, OTP and 2FA, password reset, KYC/KYB/KYE docs, reviewer and account endpoints | MongoDB, Redis |
| chat-service | 3001 | WebSocket hub for job and ticket chat, live location fan-out, support tickets and attachments | MongoDB, Redis |
| notification-service | 3004 | SSE stream, durable notification history, FCM push | MongoDB, Redis |
| user-service | 3003 | Services directory (2dsphere), jobs and dispatch, pricing, escrow, wallet, ledger, payouts, subscriptions, ratings | MongoDB, Redis |

- Real-time hubs fan out across replicas over Redis Pub/Sub and fall back to local-only delivery (ADR-0005).
- Rate limiters are Redis-backed and fail closed when Redis is unreachable (`shared/infra/ratelimit`).
- Internal calls use mTLS plus `X-Internal-Token`. The gateway strips that header from client requests.
- HTTP endpoint table: [docs/APPLICATION_MAP.md](docs/APPLICATION_MAP.md), generated by `make docs`.
  Never hand-edit between the GENERATED markers.
- Decisions: [docs/adr/README.md](docs/adr/README.md) is the source of truth (ADR-0001 to ADR-0027).
- Deploy: [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md), [docs/RUNBOOK.md](docs/RUNBOOK.md),
  [docs/STAGING.md](docs/STAGING.md), [docs/CI_CD_AND_HOOKS.md](docs/CI_CD_AND_HOOKS.md).

## Deferred by decision

- **Payments**: only `cod` in production. `wallet` is accepted only in local/test with `ALLOW_TEST_PAYMENT_BYPASS=true`.
  Config refuses that flag when `APP_ENV=production`. Card/e-wallet gateways are placeholders. See ADR-0002.
- **Owner KYC approval**: manual, through the ops CLI or the database. See the runbook section in `README.md`.
- **Tokens in query strings**: kept for WebSocket, SSE and signed document/attachment URLs (browser API limits).
  Session-JWT endpoints accept `Authorization: Bearer` first.
- **CloudWatch shipping**: one `PutLogEvents` call per event, no batching (`shared/infra/handlerutil/security_logs.go`).
- **Rating edits**: not allowed. There is no update endpoint.
- **Object storage**: local disk behind the `storage.Storage` interface (`shared/infra/storage`). No S3 provider yet.
- **National ID text search**: not implemented. IDs exist only inside document images.
- **Cargo/goods category**: not planned for launch. The home screen shows Delivery, Ride (`transport`), Shipping.
- **Standalone courier profile screen**: not planned. Details render inline on the job status and map screens.

## Known open items

Each item was re-checked against `logic-exploitation` when this file was written. Evidence is in
`docs/worklog/CLN-01.md`.

Backend:
- Audit-log pagination: `GetAuditLog` in `services/auth-service/internal/store/mongodb.go` sorts but sets no limit.
- Chat token cache has no bound or eviction: `tokenCache` map in `services/chat-service/internal/handlers/chat.go`.
- `TestComplaintRoutingConcurrency` still wraps `CreateTicketAndAssign` in a 3-attempt retry loop (`chat_test.go`).
- SSE `Last-Event-ID` replay is not implemented. The 15 s heartbeat exists.
- Chat `Hub.Run()` (`services/chat-service/internal/chat/hub.go`) loops forever with no context or stop path.
  This interacts with ADR-0005 and needs an ADR addendum.
- `BroadcastLocation` does not validate the `job:`/`fleet:` channel format. Only `X-Internal-Token` gates it.
- XFF parsing takes the first entry: `ResolveClientIP` in `services/api-gateway/internal/iputil/iputil.go`.
  The fix needs a trusted-proxy-count decision (ADR-level).
- Admin version config: the gateway uses `version.NewStore(nil, "")` (not Mongo-backed) and gates
  `/api/v1/admin/version-config` with the internal token. Both need a product decision.
- `encrypt-documents` finds already-encrypted files by trial decryption with the current key only.
  After key rotation it would double-encrypt. It has no format marker.
- Storage traversal guard uses `strings.HasPrefix(absDest, absBase)` with no trailing separator
  (`shared/infra/storage/storage.go`). Traversal is blocked elsewhere too, so impact is low.
- Inter-service URLs build query strings without `url.Values` in most places. All values come from the server (unverified sweep).
- Orphan scaffolding: `services/chat-service/cmd/onboard-agent` is still present, although the ops console replaced it (ADR-0023).
- Dev-grade mTLS CA (`infrastructure/certs/generate-certs.sh`). Production needs a real internal CA.
- Pricing uses booking coordinates sent by the client. Speed plausibility caps at `MaxReasonableSpeedKmh = 150`.
- Proposals from A6, not decided: masking payout `account_details` for reviewers, and the `GetUser` document-key gap
  against the profile parser.

Frontend:
- Request fields: the backend accepts `_token` aliases, but the Flutter client mostly still sends legacy `_id` names.
- Sentence-case migration of Title-Case EN strings: a proposal awaiting go (large golden churn).
- Employee functional findings still open: [docs/frontend/EMPLOYEE_FUNCTIONAL_FINDINGS_2026-09.md](docs/frontend/EMPLOYEE_FUNCTIONAL_FINDINGS_2026-09.md).
- UX audit 2026-09 §5 open questions Q1–Q11 were left untouched on purpose (unverified whether answered since).

Refactor backlog (no work started):
1. Reviewer auth is duplicated as `authenticateReviewer` in auth, chat and user services. Unify it in `shared/infra`.
2. Pagination parsing is repeated in admin list handlers. There is no shared `ParsePaginationParams` yet.
3. `services/user-service/internal/handlers/jobs_handlers.go` is about 3,950 lines. Split it by domain.

## Standing working rules

These rules are not in `CLAUDE.md`. Rules that `CLAUDE.md` already states are not repeated here.

- Never force-push `logic-exploitation` or `main` without explicit per-instance human approval. If a push is
  rejected because of divergence, stop and report.
- Update `docs/APPLICATION_MAP.md` (`make docs`) in the same commit as any endpoint add, remove, rename or
  auth change. Check methods and permissions against the handler code, and never leave a TODO.
- Reference integrity: when you delete, rename or materially change a file, endpoint or component, fix every
  reference in `docs/` and this file in the same commit.
- CI parity: any check added to `.github/workflows/ci.yml` goes into `.githooks/pre-push` in the same commit,
  and the reverse.
- gosec runs unfiltered (dev build, rules G704/G705/G706). Fix real findings. A false positive needs a
  `#nosec`/`//nolint:gosec -- <reason>` on that exact line. Never narrow the scan.
- A new external dependency in `shared/infra` needs `go mod tidy && go build ./...` in every importing service
  and a no-cache Docker rebuild before the change is done.
- Every pass/fail claim says where it ran: local, GitHub Actions, or both.
- Before building a frontend feature on a backend contract, grep that the contract exists. If it does not, stop
  and report.
- Parallel sessions each get their own MongoDB and Redis containers. Transport errors against a shared local stack
  look like code flakes.
- Every `.dart` file under `frontend/lib/` screens, providers and models must be listed in
  `docs/frontend/STATUS.md` (checked by `make docs-check`).
- Keep this file current. Feature status and open items must match the code.
