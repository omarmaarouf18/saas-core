# Documentation index

One row per tracked file under `docs/`, plus the root-level `DESIGN.md` and `README.md`.
Worklogs are indexed as a single row for `docs/worklog/`.

**Class**
- **Current**: maintained, and describes the system as it is now.
- **Reference**: stable decisions or specs (ADRs, design system, brand).
- **Historical**: a finished audit, report, plan or pass, kept for its record.

**Columns**
- **Modified**: last-modified date (`git log -1 --format=%as`).
- **In-links**: the number of other tracked `*.md` files whose text contains the file's basename (`grep -l`).
  Excluded from the count: the file itself and `docs/history/` (the archive copies old mentions).
  For `*/README.md` the pattern is `<parent-dir>/README.md`. For root `README.md` it is `](README.md`, `](../README.md`,
  `](../../README.md` or `(/README.md`. Basename grep counts plain-text mentions too, not only links.
