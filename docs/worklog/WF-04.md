## Decisions taken
- **Exact tree inspection**: `.githooks/pre-commit` executes `tree="$(git write-tree)"` which respects
  `$GIT_INDEX_FILE` set by `scripts/commit.sh`. It evaluates required scope `need_key` by diffing
  `HEAD` with `$tree` through `scripts/changed-scope.sh --paths`.
- **Handling untracked files in `make commit`**: When untracked files are present during `make check`,
  `worktree_tree()` (which includes untracked files) is stamped (`$view_tree`). In `scripts/commit.sh`,
  after verifying `$view_tree` against the stamp, if `$commit_tree != "$view_tree"`, `scripts/commit.sh`
  records a pass stamp for `$commit_tree` with `$need_key`. When Git executes `.githooks/pre-commit`,
  `$(git write-tree)` matches `$commit_tree` and the stamp check succeeds.
- **Merge and revert exceptions**: Owner merges via `git merge --no-ff` (detected via
  `git rev-parse -q --verify MERGE_HEAD`) and owner reverts (`REVERT_HEAD`) bypass the local stamp
  requirement because they are verified by the owner's pre-push gate and GitHub CI.
- **No escape hatch**: No environment variable bypass exists for agents or owner.
