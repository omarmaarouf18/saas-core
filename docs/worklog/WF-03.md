## Decisions taken
- **Scope computation**: default (make check) = committed since merge-base with
  `SCOPE_BASE` (default `logic-exploitation`) + staged + unstaged + untracked (not
  ignored). Untracked files are included because `go test` / `flutter test` pick them
  up. Pre-push = `<remote sha>..<local sha>` per ref line; a new remote ref is diffed
  from its merge-base with `origin/logic-exploitation` (or local `logic-exploitation`);
  a remote sha missing locally, or no base, forces FULL.
- **Mapping additions (justified)**: `shared/infra/docgen` tests read
  `services/*/internal/handlers` (APPLICATION_MAP.md route sync) and `frontend/**`
  (STATUS.md coverage, widget counts, pubspec vs DESIGN.md, l10n arb files), so a
  service or frontend change also runs `shared/infra/docgen` tests. `.gitleaks.toml`
  is gate configuration → FULL. `services/<svc>/go.mod|go.sum` → FULL (module
  definition). `CLAUDE.md` is checked BEFORE the `*.md` rule (first version had the
  order wrong and gave it the docs scope; fixed in its own commit). The Go drift
  guard runs with any Go-module scope (a Dockerfile change is a module change).
  `tests/e2e/**` is unmapped → FULL (fail safe; the gate does not run e2e at all).
- **Docs checks** = the markdown SHA check (whole repo, ~3 s); docs scope also runs
  `shared/infra` tests via `go-test-module.sh` (as the mapping requires).
- **Test cache mechanism (item 4): linkage-based package list.** For each test
  package, `go list -test -deps` decides: if the test binary links
  `go.mongodb.org/mongo-driver` or `github.com/redis/go-redis/v9` it is
  *integration* (`-count=1`, under the lock); `shared/infra/docgen` is a
  *repo-reader* (`-count=1`, no lock: it walks docs/, frontend/, services/ and the
  Go cache's file tracking is not trusted for scans that broad); everything else is
  *unit* (plain `go test`, cacheable). Rejected: a build tag (needs edits to many
  test files outside the lane, and a forgotten tag silently caches an integration
  test); an env var (tests would have to opt in). Linkage fails safe: a test cannot
  reach Mongo/Redis without linking a driver; a package that links one only for a
  fake still runs every time. Honest result: almost all test time is in integration
  packages (user/auth/chat handlers link the drivers), so the cache saves little
  today — see timings.
- **Lock (item 5)**: only `go test -count=1` of integration packages takes
  `<git-common-dir>/ci.lock`. The hook no longer locks; `make ci` no longer locks.
  `CI_LOCK_HELD=1` still means "caller holds it".
- **Stamp key (item 6)**: the tree of (copy of the real index + every tracked change
  + every untracked, not ignored file, from disk). `make commit` builds the exact
  commit tree in a scratch index (same steps as the real commit; the real index is
  not touched when it refuses), adds the untracked files it leaves out, and needs a
  stamp for that tree whose scope covers `changed-scope.sh --paths` of the commit.
  Consequence (documented): tracked changes outside FILES make it refuse (listed,
  with the stash remedy), because the checked tree would differ from the committed
  one. Untracked files are tolerated (a new worklog stays untracked until its own
  final commit, as the task rules require). A run whose tree changes while it runs
  writes no stamp. Stamps: `<git-common-dir>/gate-stamps/<tree>`, pruned >14 days /
  beyond 200. No bypass variable was added; a raw `git commit` does not check stamps.
- **gitleaks (item 7)**: v8.30.1 (released 2026-02-21; latest at the time), built
  with `go install` by `scripts/install-tools.sh` into the versioned tool cache.
  **Ranges only, no baseline**: old staging credentials removed in 212cb050 are in
  `370893d2` (infrastructure/staging/.env.staging.example ×5, tests/e2e/e2e_helpers.go)
  and `1b65d53d` (tests/e2e/e2e_helpers.go) — counts from a one-off redacted full

  …) still fires in tests; `frontend/build/`. Example env files are deliberately NOT
  allowlisted (that is exactly where the old real secrets were). make check scans
  merge-base..HEAD + staged + unstaged + untracked files, too (cheap, ~0.1 s).
- **Compose validation** (new `scripts/compose-validate.sh`): needs no secret. Uses
